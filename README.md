## 🚀 What I've Built (Live Products)

> Most of my production work lives in private client repos. Here's what it is, what it does, and where it runs — case-study repos with architecture deep-dives are pinned below.

### 🎙️ [LetAI Handle](https://letaihandle.com) — AI Voice-Calling SaaS
Businesses deploy AI phone agents that hold natural conversations, book meetings, and run outbound campaigns autonomously.
- Real-time streaming **STT → LLM → TTS** pipeline with **barge-in handling** and per-turn latency instrumentation
- **RAG** over a custom knowledge base (OpenAI embeddings + **pgvector**) answering from business data mid-call
- Autonomous outbound dialer with an **LLM decision brain** driving timezone-aware, multi-stage lead retries
- `FastAPI · PostgreSQL + pgvector · OpenAI · Twilio · Deepgram · ElevenLabs · Razorpay`

### 🛒 [DermOffice Store](https://shop.drellenturner.com) — E-Commerce Platform
Custom storefront + admin + API for a US dermatology clinic — **processing ~$30K/month in live sales**.
- Webhook-verified payments: orders become PAID only via **signature-verified Stripe webhooks**, with real fee capture for true profit reporting
- Multi-location inventory, granular **RBAC**, promo offer engine, staff commission splits, Instagram/Facebook sales channel via automated Meta catalog feed
- `Next.js · NestJS · Prisma · PostgreSQL · Stripe`

### 🏠 [Property Doctors](https://rentalprosolution.com) — Property-Management SaaS
Multi-tenant platform digitizing the full rental lifecycle for letting agencies and independent landlords.
- Six user roles with strict **company-scoped data isolation**
- **Double-entry ledger** with row-locked transactional postings and invariant-checking reconciliation
- Webhook-driven rent collection (HMAC-verified), automated billing crons, real-time Socket.io workflows
- `Next.js · Express · MySQL · Socket.io`
